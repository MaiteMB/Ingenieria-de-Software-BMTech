Inicio

El menu muestra las gestiones permitidas para el usuario conectado. La opcion Ayuda abre esta guia. Desde los formularios tambien se puede solicitar ayuda con F1. No se necesita conexion a Internet para consultar estos archivos.

Ingresar y salir

Ingresar el email y la contrasena de la cuenta. Una cuenta bloqueada debe ser revisada por el administrador. Al tercer intento incorrecto se bloquea el acceso. Salir desde el menu o cerrar la ventana principal termina la sesion.

Preparar integridad se utiliza solamente despues de una instalacion o actualizacion que necesita inicializar los digitos. Si aparece una diferencia inesperada, revisar la causa; no preparar ni regenerar para ocultarla.

Clientes

Completar DNI, nombre, apellido, telefono y correo electronico. Registrar guarda el cliente si sus datos son validos y el DNI no existe. Para utilizarlo en una venta o un ingreso de servicio tecnico debe estar registrado previamente.

Productos

Buscar el producto, seleccionar su fila y consultar los datos antes de modificar. El codigo no debe repetirse, el precio debe ser mayor que cero y el stock no puede ser negativo. Desactivar evita nuevas operaciones con el producto sin borrar sus ventas anteriores.

Ventas, pagos y comprobantes

  1. Buscar al cliente y seleccionar los productos y cantidades.
  2. Revisar el detalle y el total. Quitar producto elimina una linea de la venta todavia no guardada.
  3. Registrar el pago. Una transferencia requiere numero de operacion. Marcar verificado solo despues de comprobar el pago real.
  4. Una venta pendiente no descuenta stock. Confirmar su pago desde Historial de ventas cuando corresponda.
  5. Generar el comprobante y registrar la entrega. El comprobante se puede consultar y exportar a PDF o XML.

Desde el historial se puede cancelar una venta pendiente. No se deben registrar ventas nuevas para corregir pagos de una venta anterior.

Servicio tecnico

  1. Usar Nuevo ingreso. Completar DNI del cliente, identificacion del equipo, problema y accesorios, y registrar.
  2. Seleccionar la orden en el listado. En Asignacion elegir un tecnico activo y la prioridad.
  3. El tecnico asignado registra la falla, el trabajo propuesto y los dias estimados. El administrador puede intervenir si necesita corregir la gestion.
  4. Generar el presupuesto con mano de obra y repuestos. Registrar la comunicacion cuando realmente se realizo y despues cargar la respuesta del cliente.
  5. Con el presupuesto aprobado, registrar las nuevas tareas y los nuevos consumos. Los consumos guardados aparecen en la grilla de usados: no agregarlos de nuevo. El stock se descuenta al confirmar.
  6. Registrar las pruebas. Si no son satisfactorias la orden sigue en reparacion. Registrar el aviso al cliente cuando se haya efectuado; BMTech no envia mensajes automaticos.
  7. Al retirar, comprobar el pago por el importe aprobado, completar quien retira y la garantia y confirmar. Ver comprobante permite consultar el cobro, exportar PDF o serializarlo como XML.

Un presupuesto rechazado permite devolver el equipo sin registrar un cobro de reparacion. Un presupuesto nuevo antes de la aprobacion conserva el anterior y requiere comunicarlo otra vez. Si la orden cambio, actualizarla antes de confirmar.

Informes

Seleccionar Ventas o Servicio tecnico, indicar Desde y Hasta y buscar. Las fechas incluyen ambos dias. El informe de ventas separa importes cobrados y pendientes; las canceladas no se suman. El informe de servicio incluye los comprobantes de cobro emitidos, no las ordenes sin cobrar. Exportar PDF vuelve a consultar los datos con los permisos vigentes.

Control de cambios de productos

Seleccionar una version y revisar su detalle antes de restaurarla. Restaurar reemplaza los datos del producto, incluido su stock, y conserva el estado reemplazado en el historial. No cancela ventas ni reparaciones existentes. No permite recuperar un producto eliminado fisicamente. Solo un usuario con permiso de Seguridad puede realizar esta operacion.

Usuarios, permisos y contrasena

El administrador registra usuarios, asigna perfiles y revisa los bloqueos. Los perfiles y familias agrupan los permisos. No se permite quitar al administrador su propio acceso a Seguridad. Cambiar contrasena solicita la actual y dos veces la nueva; ninguna se guarda como texto legible.

Idiomas

El selector cambia las leyendas disponibles sin reiniciar. Maestros permite mantener idiomas y traducciones. Si una leyenda no tiene traduccion se conserva la original. Los datos ingresados por los usuarios no se traducen.

Bitacora

Buscar por fechas y, si corresponde, por usuario o actividad. La consulta no permite editar ni borrar eventos. El historial de cambios de productos se consulta en otra gestion.

Copias e integridad

Crear copia guarda un archivo .bak y su .bak.key. Conservarlos juntos y en un lugar privado. La cuenta de SQL Server necesita acceso a la carpeta elegida. Restaurar reemplaza los datos actuales, recupera la clave y cierra la aplicacion; primero realizar una copia actual.

Si falla una verificacion, anotar las tablas informadas y avisar al administrador. Regenerar acepta los datos actuales como referencia; no recupera datos ni reemplaza una copia de seguridad.
