BMTech - Instalacion y mantenimiento

Ayuda y guia de usuario | Operacion diaria

Requisitos

Windows, .NET Framework 4.8 y una instancia de SQL Server compatible con SESSION_CONTEXT. La aplicacion usa autenticacion de Windows. La cuenta que se conecta necesita los permisos de base correspondientes; crear la base requiere autorizacion del servidor.

Primera instalacion

Ejecutar BMTech_Setup.exe y seguir los pasos del asistente. El instalador controla que este .NET Framework 4.8, copia el programa en Archivos de programa\BMTech y crea los accesos directos en el escritorio y en el menu Inicio. Si el equipo no tiene SQL Server, instala SQL Server Express. Al terminar crea la base BMTech con un administrador y un empleado. La opcion Cargar datos de prueba agrega clientes, productos, una venta y ordenes de servicio de ejemplo. El instalador no reemplaza una base existente; si no puede crearla, el detalle queda en InstalacionBase.log, en la carpeta del programa.

Las cuentas iniciales son admin@bmtech.com y vendedor@bmtech.com, con clave 1234. Cambiar las claves antes de usar informacion real.

Crear la base manualmente

La base se crea con el script CrearBaseBMTech.sql y los datos de prueba se cargan con DatosDePruebaBMTech.sql, ambos en la carpeta BaseDatos. Para crearla sin PrepararBase, abrir CrearBaseBMTech.sql en SQL Server Management Studio y ejecutarlo. Despues, en la pantalla de ingreso, usar Preparar integridad con el usuario administrador. El script no reemplaza una base existente.

Conexion

La clave ServidorSql del archivo de configuracion identifica la instancia. BMTECH_SQL_SERVER permite reemplazarla en un entorno de prueba. BMTECH_SQL_DATABASE se utiliza para las bases aisladas de las pruebas; no debe quedar configurada en el uso habitual. No se necesitan contrasenas SQL en el archivo.

Copias y recuperacion

Conservar varias copias fechadas, con sus claves, fuera del equipo de trabajo cuando sea posible. Probar una restauracion en un entorno separado antes de depender de una copia. La clave AES de uso local se guarda en el area local de datos de Windows; no borrarla ni publicarla. Una copia sin su clave puede impedir recuperar los datos cifrados.

Desinstalacion y resguardo

BMTech se quita desde Configuracion, Aplicaciones, como cualquier programa instalado. Quitar la aplicacion no debe borrar automaticamente la base, las copias ni las claves. Su eliminacion debe decidirla el responsable despues de conservar la informacion necesaria.
