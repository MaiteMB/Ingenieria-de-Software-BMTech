# Ingeniería-de-Software-BMTech



Proyecto integrador de Ingeniería de Software y trabajo de diploma.



BMTech es un sistema de gestión orientado a un local de informática y servicio técnico. Su objetivo es centralizar y organizar la información del negocio, facilitando el seguimiento de sus principales operaciones, clientes, productos y equipos ingresados para reparación.



El proyecto se desarrolla de manera incremental a partir de los requerimientos definidos durante la materia, buscando representar y resolver las necesidades reales del negocio mediante una solución de software.
